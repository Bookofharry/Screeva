- [ ] **UX-3 — Recording actions and truthful statuses.** State-aware sticky bottom recording dock (`Durable local session` default when service is connected); clear `Start recording` / `Pause` / `Resume` / `Stop` hierarchy; prominent `● REC` indicator, `document.title` prefix, optional skippable 3-second countdown, and `beforeunload` guard; distinct `Creating session`, `Recording`, `Paused`, `Stopping`, `Uploading` (determinate drain progress), `Retrying`, `Finalizing` (indeterminate validation), `Saved`, `Failed`, and offline states. Confirm `Saved locally` only after validated server completion (`output !== null`).
- [ ] **UX-4 — Session library and recovery experience.** Render `Recordings` view from `GET /api/v1/sessions` (truthful metadata without inventing unimplemented playback/open/delete routes); surface launch banner/badge for unfinished sessions and auto-refresh `RecoveryPanel` after durable failures; clarify explicit salvage of server-acknowledged bytes only while respecting active leases and corrupt-session quarantine.
- [ ] **UX-5 — Accessibility and usability validation.** Guarded single-key shortcuts (`R`, `P`, `Escape` with off switch and input/modifier guards per WCAG 2.2 SC 2.1.4), manual keyboard/screen-reader/reduced-motion checks, `375px` / `768px` / `1280px` / `1440px` layout verification, real permission prompts, and 5-participant representative usability sessions with recorded outcomes.

### UX safety acceptance gate

- [ ] No regression to source track ownership or cleanup; no re-request of media permissions by UI-only code.
- [ ] No regression to localhost Host/Origin/Fetch Metadata/write-token protections; no persistent credential storage.
- [ ] Existing 32 MiB upload queue (`64` chunks) and 128 MiB temporary recording limits preserved unless separately approved.
- [ ] False-success scenarios (lost ACK, corrupt probe, server unavailable, token rotation) never show `Saved`.
- [ ] Recovery describes only previously acknowledged and independently verified bytes; corrupt sessions remain isolated.
- [ ] All UX milestones have tests, screenshots, and separate evidence of manual versus automated verification.
- [ ] Missing actual FFprobe/FFmpeg and real-device acceptance continue to be reported independently, not hidden by UX completion.
