## Verified Phase 3 Task 5B implementation — 2026-11-11
- Added `DurableRecordingEngine`, a React-independent coordinator that bootstraps the launch token, creates a persistent session before MediaRecorder starts, streams non-empty emitted Blobs into the existing bounded pipeline/transport, drains validated durable ACKs after the final browser chunk, and requests idempotent finalization with the exact acknowledged count.
- RecordingEngine now has a streaming sink mode alongside unchanged temporary mode. Streaming mode forwards each original Blob without appending it to the whole-recording array or creating a result object URL. The transport/pipeline retain the single original Blob identity only until its durable ACK; one upload remains in flight per session. Temporary preview/download and its 128 MiB cap remain available and unchanged.
- Durable mode exposes creating, recording, paused, stopping, uploading, retrying, finalizing, failed and Saved UI states. Saved is shown only after strict finalization response validation. Active compositor layout/resolution and mixer audio mode are stored in the session configuration. The shared capability contract now reports the reliability milestone with recording available and export unavailable.
- Stop includes the browser's final `dataavailable`, waits for pending hashes and transport drain, then finalizes. Finalization network loss/timeout and transient server responses retry up to three times. Invalid tokens, terminal ACK/protocol errors, source loss, queue saturation and upload exhaustion fail visibly without stopping capture/compositor/mixer-owned tracks or claiming success.
- The existing 64-item/32 MiB transport queue is durable mode's retained-memory bound. High water must remain active for two seconds before safe encoder stop; hard-cap and terminal transport failures stop immediately. Reset/unmount cancels timers, requests and retained client queue state. Already acknowledged server chunks remain; reload does not claim completion and recovery UI remains explicitly out of scope.
